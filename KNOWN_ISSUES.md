# Known Alpha limitations

- New biomes, trees, and structures appear only in newly generated chunks.
- Biome footprint, vegetation density, and structure frequency may change during Alpha development.
- The Springhouse is included as a placement template but does not generate naturally.
- White-oak and yellow-poplar building stock currently begins through conversion recipes rather than custom naturally generated trees.
- Lowbush Blueberry is decorative and does not yield berries.
- Some furnishing props are decorative rather than storage or processing blocks.
- This Alpha does not add custom animals.
- A small number of in-game labels do not yet use the current project title. Registry IDs remain unchanged for compatibility.
- Optional seasonal behavior and shader presentation may change as compatibility work continues.
- Removing the mod from an established save can leave missing registry content. Keep backups.
- Compatibility outside the exact version baseline in [INSTALLATION.md](INSTALLATION.md) is not guaranteed.
